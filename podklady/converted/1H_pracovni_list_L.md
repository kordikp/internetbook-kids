# JAK VYPADÁ INTERNET

## 1. Jaké činnosti můžeme dělat na digitálním zařízení, když jsme a když nejsme připojeni k internetu?

> **Popis obrázku:** Vennův diagram tvořený dvěma velkými překrývajícími se zaoblenými ovály přes celou šířku stránky. Levý ovál (plná čára) je nadepsán „pouze **online**“, pravý ovál (přerušovaná čára) „pouze **offline**“ a jejich průnik uprostřed je nadepsán „**online** i **offline**“. Všechny tři oblasti jsou prázdné – žáci do nich vpisují činnosti.

## 2. Co je uloženo na těchto serverech?

> **Popis obrázku:** Řada jedenácti malých ikon serverů (obdélníčky se zaoblenými rohy naznačující serverovou skříň) rozmístěných ve dvou řadách. U každé ikony serveru je vodorovná linka na doplnění odpovědi – žáci k jednotlivým serverům píší, co na nich může být uloženo (např. sociální sítě, hry, videa, mapy, e-shopy, webové stránky).

## 3. Zamyslete a prodiskutujte ve skupině. Sem si pište argumenty:

**A.** Má internet nějaké **řídící centrum**? Má ředitele? Proč si to myslíte?

**B.** Co by se stalo, kdyby někdo **překopl internetový kabel** vedoucí mezi Prahou a Brnem? Budeme moci z Brna napsat zprávu přes Instagram kamarádce, která je v Praze? Proč?

*(Pod oběma otázkami je volný prostor na zápis argumentů.)*

## 4. Zapište k novým pojmům číslo správného vysvětlení:

| Pojem (s rámečkem na číslo) | Vysvětlení |
|---|---|
| SERVER | 1. Prostor, kde se nachází velké množství serverů. |
| DATOVÉ CENTRUM | 2. Počítač, kde je uloženo velké množství dat (například webové stránky, videa, herní skóre či naše zprávy), a který poskytuje nějaké služby. |
| WI-FI ROUTER | 3. Po internetové síti směruje data až k cíli (např. k serveru webové stránky). |
| SÍŤOVÝ ROUTER | 4. Zařízení, které nám umožňuje se připojit přes Wi-Fi. |

> **Popis obrázku:** Vlevo jsou čtyři pojmy pod sebou, u každého je prázdný čtvereček, do kterého žák zapíše číslo správného vysvětlení z pravého sloupce. (Správné řešení podle prezentace: server = 2, datové centrum = 1, Wi-Fi router = 4, síťový router = 3.)
